## SEO Image Optimization Best Practices
1. **Format**: Convert images to `.webp` or compressed `.jpg` using tools like Squoosh.app or TinyPNG to maintain file sizes under 150KB.
2. **Aspect Ratio**: Keep a consistent 3:2 or 16:9 ratio to avoid Cumulative Layout Shift (CLS).
3. **Alt Text**: Never stuff keywords into `alt` tags; describe the visual content clearly and naturally.
